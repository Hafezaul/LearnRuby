Apa yang sudah dipelajari?

Catatan ini merangkum materi yang benar-benar terlihat di file Ruby dan README repo. “Sudah ada” berarti ada contoh atau penjelasan, bukan berarti penguasaan sudah teruji. Tidak ada histori belajar atau test yang memungkinkan menilai kemampuan/praktik secara pasti.

Ringkasan isi repo

SUDAH ADA CONTOH

Dasar program, variabel, dan input

Output puts/p/print, komentar, assignment, interpolasi string, String/Integer/Float/Boolean. Contoh input nama dan umur memakai gets.chomp serta to_i.

SUDAH ADA CONTOH

String

String multiline, size/length, upcase, downcase, reverse, include?, dan contoh freeze.

SUDAH ADA CONTOH

Operator dan kondisi

Aritmatika dasar, ==/!=/>/</>=/<=, <=>, eql?/equal?, serta if, elsif, else, ternary, dan unless.

SUDAH ADA CONTOH

Array

Akses indeks dan at/fetch, first/last, take/drop, tambah/hapus elemen, dan uniq/uniq!. Materi Array paling terperinci di repo, dengan contoh dan catatan terpisah.

SUDAH ADA CONTOH

Hash

Hash dengan symbol key, akses value, menambah/mengubah entry, dan perbandingan kegunaan dasar Array dengan Hash.

BARU DISEBUT / BELUM JELAS

Jenis variabel dan case

README menyebut global, instance, class variable, dan constant; detail contoh instance variable belum lengkap. case ada di daftar topik kondisi, tetapi belum tampak contoh implementasinya.

Yang belum terlihat di repo

Ini adalah topik lanjutan yang wajar dipelajari berikutnya—bukan kekurangan yang harus diselesaikan sekaligus:

  • Loop dan iterasi, method buatan sendiri, blok, Proc/Lambda, serta Enumerable.
  • Symbol lebih dalam, nil, logika boolean, range, dan pola pengolahan data.
  • Class/object, constructor, enkapsulasi, inheritance, module/mixin.
  • Exception dan validasi input; baca/tulis file, JSON/CSV, dan pemecahan kode dengan require.
  • Testing otomatis, Bundler/Gemfile, dependency, formatter/linter, dan pengorganisasian proyek.
  • Database, web/Rails, API, atau otomasi—pilih setelah dasar Ruby kembali nyaman.
Rekomendasi praktis: mulai dengan menjalankan dan mengubah contoh yang sudah ada; setelah itu buat satu proyek CLI kecil. Proyek memberi latihan nyata pada method, koleksi, input, file, error, dan testing.

Catatan ketelitian untuk dibaca ulang

Lokasi materiYang perlu diperjelas saat mengulang
1.variabel/README.md Constant Ruby lazimnya ditulis dengan huruf kapital di awal (misalnya MAX_SIZE); daftar yang ada justru mencontohkan nama huruf kecil. Variabel global dapat diakses luas, tetapi sebaiknya digunakan hemat. Instance/class variable perlu dipelajari dalam konteks objek dan class.
5.array/9.array.delete/README.md Array#delete menghapus elemen berdasarkan nilainya, bukan indeks. Contoh menghapus angka 2 memang menghapus nilai 2. Untuk menghapus berdasarkan posisi, pelajari delete_at(index).
5.array/12.array.uniq/README.md uniq mengembalikan array baru tanpa mengubah array asal. uniq! mengubah array asal bila ada perubahan, dan dapat mengembalikan nil jika memang tidak ada perubahan. Hindari anggapan semua method bertanda ! punya perilaku yang sama.
2.string/README.md Contoh mengubah string dengan << sebelum freeze, lalu mutasi lagi setelah objek dibekukan. Mutasi setelah freeze akan memunculkan FrozenError; perubahan sebelum dibekukan sudah menetap pada objek itu.
6.hash/README.md Key yang tidak ditemukan pada Hash biasa mengembalikan nil (bukan “nill”). Bisa juga mengecek keberadaan key secara eksplisit dengan key?.
main.rb dan latihan_satu.rb Daftar nama pada main.rb berada di dalam komentar blok, jadi tidak dijalankan. Contoh uniq!.sort bergantung pada adanya duplikat: bila uniq! tidak mengubah array, hasilnya nil dan chaining .sort akan gagal. Untuk contoh yang tahan kondisi tanpa duplikat, gunakan uniq.sort.
Seluruh repo Belum terlihat Gemfile, test suite, atau latihan dengan hasil yang diverifikasi otomatis. Buat test kecil ketika mulai membangun program agar perubahan lebih aman.

Urutan paling masuk akal untuk kembali belajar

  1. Jalankan ulang file contoh dan pastikan kembali paham materi dasar yang memang sudah ada.
  2. Isi celah dekat: case, loop, method, blok, dan Enumerable.
  3. Bangun pemahaman class/object dan praktikkan dengan data Hash/Array.
  4. Tambahkan file, validasi/error handling, dan test ke satu proyek CLI kecil.
  5. Baru lanjut ke Rails/web atau topik Ruby lain sesuai tujuanmu.
